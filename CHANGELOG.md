# Changelog

## 1.9.0

- Forge and Fabric builds now cover Minecraft 1.16.5, 1.18.2, 1.19.2, 1.20.1 and 1.21.1. Minecraft 1.12.2 has separate builds for Forge and Legacy Fabric. The original NeoForge build targets 1.21.1.
- The older Overworld generators now build the road network, village turnings, bridges, supported tunnels and roadside stops. On a suitable shore, the road ends at a wooden pier. Some piers have a lighthouse.
- TerraFirmaCraft support includes Classic on Forge 1.12.2, TFC on Forge 1.18.2 and 1.20.1, and TFC on NeoForge 1.21.1. In Classic, masons use andesite and the side roads use local gravel and soil.
- The source code and original artwork are available under the MIT licence.

Use the same Minecraft version and loader on the client and server. Roads generate as you explore new Overworld chunks. The [build table](ports/README.md) lists the tested loaders, Fabric API versions and TerraFirmaCraft dependencies.
